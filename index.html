¿Qué recibo al comprar ALABA? +

Recibes el paquete de clips correspondiente a la versión y formato adquirido. Consulta las secciones incluidas antes de completar tu compra.

¿Los videos tienen fondo transparente? +

Los archivos de producto se preparan con canal alfa para permitir la superposición de las letras sobre otros elementos visuales. Tu programa debe admitir el códec utilizado.

¿Puedo ver el video antes de comprar? +

Sí. Puedes reproducir la vista previa gratuitamente desde el catálogo antes de decidir tu compra.

¿MOV y WEBM cuestan lo mismo? +

Sí. Para ALABA, la versión MOV cuesta $5.00 USD y la versión WEBM también cuesta $5.00 USD. Se venden por separado.

¿Cómo puedo realizar el pago? +

Selecciona tu formato y utiliza el enlace de compra de PayPal. La entrega de archivos se realiza después de la confirmación del pago, conforme al sistema configurado por la tienda.

¿Puedo solicitar otra canción? +

Sí. Puedes escribirnos mediante WhatsApp para consultar la posibilidad de realizar una animación personalizada.
